## 协作入口

局域网普通账号：

```bash
ssh lec@192.168.5.7
```

公网参数由管理员私发；下面是模板，先替换主机和端口：

```bash
ssh -p PUBLIC_SSH_PORT lec@PUBLIC_SSH_HOST
```

SFTP 使用相同参数。普通协作者不需要获得樱花访问密钥、远程管理密码或 root 密码。

LAN PVE 网页：`https://192.168.5.7:8006/`。公网通过 SSH 本地转发打开网页，不另公开 8006，详见[维护手册](docs/operations.md#远程访问-pve-网页)。当前只有 `root@pam` 注册为 PVE 用户，没有为 lec 配置网页管理权限。

## 必须知道的现状限制

1. **版本维护**：Debian 12 LTS 覆盖范围有限，支持到 2028-06-30；PVE 8 自身支持已于 2026-08 结束。用户因投入生产决定暂不升 PVE 9，不代表当前所有组件仍受维护。[Debian 说明](https://www.debian.org/releases/bookworm/)、[PVE 生命周期](https://forum.proxmox.com/threads/proxmox-ve-support-lifecycle.35755/)
2. **更新源**：当前启用的源中缺少 PVE 主仓库；不能用“没有待升级包”推断 PVE 更新完整。
3. **容器开机启动**：CT 103 虽设 `onboot: 1`，但宿主机 `pve-guests.service` 是 masked/inactive；不能承诺业务重启后自动恢复，本次未重启验证。
4. **存储不是多份备份**：Data、System、local 都在宿主机根文件系统；local-lvm 也是同一 PVE 设备上的 thin pool，不能替代外部备份。
5. **共享账号没有人员隔离**：lec 使用同一 UID；多人可改同账号可写文件，也可能终止同账号进程。无 sudo 不等于无法影响协作者。
6. **公网入口安全**：root 密码登录已开启；宿主机防火墙当前未启用过滤。暴露过的凭据是否全部轮换未确认，不在仓库复述。
7. **待验证范围**：物理硬盘数量、RAID 级别、硬盘健康、IPMI、完整外部业务备份和恢复测试尚未确认。

这些问题本次只记录，不修复；仓库文档不授权生产变更。

## 公开与私密边界

本仓库不存放真实公网管理入口、隧道 ID、密码、账户访问密钥、启动器远程管理密码、SSH 私钥、业务 .env、数据库 / 对象存储备份、用户数据或原始访问日志。使用 `PUBLIC_SSH_HOST` / `PUBLIC_SSH_PORT` 作为公网占位符。

LAN 地址、服务路径和容量用于解释当前配置；设备名不能替代磁盘身份核对。配置加密备份不等于完整业务备份；后续生产变更须另行授权并验证，再更新这里的记录。
