实验室服务器的配置记录与使用规划。本文基于现场截图和已完成的检查，仅记录已确认情况；未确认项不作为部署依据。

## 系统与存储现状

当前默认启动 **CentOS 7**，已恢复管理员登录，局域网 SSH 连接可用。另一磁盘设备保留了旧 **Proxmox VE（PVE）** 系统与虚拟机存储。

以下设备名仅代表当前启动中的识别结果，后续可能变化；安装系统前必须重新核对目标设备。

| 当前设备 | 系统与存储内容 | 验证状态 |
| --- | --- | --- |
| `sda`，约 1.8 TiB | CentOS 7；约 1 GiB `/boot`、50 GiB 根分区、31.5 GiB swap，其余主要为 `/home`；业务文件系统为 XFS | 当前正在运行 |
| `sdb`，约 1.8 TiB | 旧 PVE；Debian 11 底层系统，约 96 GiB ext4 根卷、8 GiB swap，以及约 1.67 TiB LVM thin pool | 旧系统根卷已只读访问，尚未验证独立启动 |

旧 PVE 中已发现：

- PVE 配置数据库及其 WAL、SHM 配套文件。
- 编号为 100、101、102、103、106 的虚拟机磁盘，以及部分历史快照。

PVE 具体版本、虚拟机用途、数据完整性和可启动状态尚未确认。Thin pool 容量并不代表实际业务数据量，备份空间需求需单独评估。

**当前尚未完成外部备份，也未完成新系统安装。暂不格式化或覆盖旧存储。** 数据保留范围需与原维护人员确认，不限定为某一个历史服务。

## 后续使用规划

服务器主要计划用于 **打卡系统后端与数据库**、**官网及相关 Web 服务**。不要求安装桌面环境。

1. **盘点与备份**：确认旧 PVE、虚拟机和其他业务文件的保留范围，完成外部备份及恢复检查。
2. **基础检查**：核实 CPU、存储与 RAID 配置，检查硬件健康，排查 USB 和安装介质启动问题。
3. **确定系统方案**：评估恢复使用旧 PVE，或安装新的无桌面 Debian。当前 CentOS 作为临时检查和迁移环境，不作为最终部署方案。
4. **配置管理入口**：完成稳定的局域网寻址、管理员账号、SSH 密钥与远程接入配置。换系统后重新验证 SSH 和 FRP，不假设旧配置自动迁移。
5. **部署业务**：部署官网、打卡系统与数据库；通过反向代理和 HTTPS 提供网站访问，数据库不直接暴露公网。
6. **建立维护流程**：记录部署步骤，设置服务自启动、日志管理、监控和定期备份，并验证恢复流程。

打卡记录可能涉及个人信息，部署前需明确数据保留期限、备份保护方式及访问权限。网站公开访问与服务器管理权限应分开管理。

## 维护约定

- 本仓库记录配置与部署说明，不存放生产业务数据、数据库备份、密码、私钥或认证令牌。
- 在保留范围和备份结果确认前，不清除 RAID 配置、不初始化或格式化旧数据设备。
- 任何系统切换或重装前，核对安装目标与备份；完成后更新本文中的实际配置和验证状态。
